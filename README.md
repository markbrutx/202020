# EyeBreak — 20-20-20 для macOS

Каждые 20 минут экран блокируется на 20 секунд: встань и посмотри на что-нибудь в 6 метрах (20 футах).

- Живёт в меню-баре, показывает время до перерыва
- Заслонка на всех мониторах поверх всего (включая fullscreen-приложения и меню-бар)
- Во время перерыва клавиши не работают, пропустить нельзя
- Меню: перерыв сейчас, отложить на 5 минут, пауза на 1 час
- После пробуждения мака отсчёт начинается заново

## Сборка

```sh
./build.sh            # соберёт dist/EyeBreak.app
./build.sh --install  # + положит в /Applications и запустит
```

Требуется Xcode / Swift 5.9+, macOS 13+.

Автозапуск: Системные настройки → Основные → Объекты входа → добавить EyeBreak.app.
